# 랄프톤 과제: 3D 가구 배치 시뮬레이터

KAI 12기 랄프톤(2026-11-30) 공통 과제의 스타터 레포다. 과제 명세, 기본 폴더 구조, 규칙 파일 템플릿, 예시 데이터가 들어 있다.

## 배경

아이가 생기고 이사를 가게 되면서 만들었던 3D 가구 배치 시뮬레이터가 있다. 새 집 도면을 캡처해서 올리면 3D 공간으로 바꿔 주고, 상품 링크로 가구를 가져와 실제 크기로 놓아 보고 3D로 둘러보는 도구다. 대부분의 사람들이 한 번쯤은 필요성을 느꼈을 일이기에, 이 시뮬레이터를 조금 더 간소한 기능으로 Ralph Loop를 통해 3시간 안에 구현해 보는 것을 과제로 한다.

## 만들 것

사용자가 Claude 계정을 연결하고 평면도 캡처와 상품 사진을 올리면, 앱이 Claude Agent SDK로 이미지를 읽어 도면과 가구 파일을 만들고, 이를 2D 도면과 3D 공간으로 보여 주며 배치 규칙 위반을 표시하는 웹 앱을 만든다.

외부 API 키는 쓰지 않는다. 이미지 인식은 앱 서버에서 Claude Agent SDK를 호출해 처리하고, 각자 Claude Code에 로그인한 Claude Max 사용량을 쓴다. 모델은 Claude Sonnet 5.5로 고정한다. 에이전트 구성과 도구 선택은 참가자가 정한다.

### 필수 기능

필수 기능 5개를 모두 구현하면 최소 완료로 본다. 선택 기능은 필수 기능이 끝난 뒤에 진행한다.

1. 앱에 'Claude 계정 연결' 버튼을 두고, 누르면 공식 로그인(`claude auth login`)을 실행한 뒤 `claude auth status`로 연결 상태를 표시한다. 연결된 상태에서 평면도 캡처 이미지를 올리면 Agent SDK로 Claude를 호출해 도면 파일(JSON)을 만든다. 예시 평면도를 넣었을 때 방 개수가 정답 도면과 같고 면적이 대략 맞아야 한다.
2. 도면 파일로 2D 도면을 그린다. 벽, 문과 여닫이 범위, 창문, 방 이름과 면적(㎡, 평)을 포함한다. 예시가 아닌 도면을 넣어도 동작해야 하며, 시연 때 다른 평면도로도 확인한다.
3. 같은 도면으로 3D 공간을 만든다. 벽의 길이·두께·높이와 문·창문 자리가 반영되어야 하고, 마우스로 시점을 돌릴 수 있어야 한다.
4. 가구는 목록에서 고르거나, 상품 사진(상세 페이지 캡처)을 올리면 Agent SDK로 이름·크기·가격을 읽어 추가한다. 2D에서 끌어서 옮기고 90도 단위로 회전하며, 크기는 실제 cm 비율을 따르고 3D에도 같은 자리에 나타난다. 배치는 JSON 파일로 저장되어 새로고침 후에도 그대로 불러온다.
5. [RULES.md](RULES.md)의 규칙(가구 간 겹침, 벽 밖 배치, 문 막힘 등)을 위반한 가구를 표시하고 위반한 규칙을 보여 준다.

### 선택 기능

- 가구 목록과 총 가격 표시, 배치안 여러 개 저장과 전환
- "아기 방 꾸며 줘"처럼 말로 요청하면 Agent SDK로 Claude가 규칙 위반 없이 가구를 배치
- 변환된 도면을 2D 화면에서 고치기(벽 길이, 문 위치)
- 가구 종류별 3D 모델, 1인칭 시점 이동
- RULES.md의 선택 규칙(R4, R5)

상품 링크로 가구 가져오기, 로그인과 DB, 모바일 화면은 범위에서 제외한다.

## 진행 방식

11:00~14:00에 규칙과 완료 조건을 설계하고, 14:00~17:00에 루프를 실행한다. 17:00에 결과를 시연한다.

완료 조건(DoD)은 참가자가 작성한다. 필수 기능마다 확인 방법을 적되, 자동 테스트로 확인할 항목(면적 계산, `samples/` 위반 개수, 저장과 불러오기)과 사람이 브라우저에서 확인할 항목(평면도 변환 결과, 화면, 드래그, 3D)을 구분한다. 자동 테스트는 미리 저장해 둔 변환 결과로 돌리고, 실제 Claude 호출은 확인용으로 한 번만 한다. AI가 작업을 끝냈다고 보고해도 DoD 확인을 통과하지 못하면 완료로 보지 않는다. 필수 기능을 다 끝내지 못한 경우 통과한 항목만큼 부분 달성으로 본다.

Loop 규칙 파일에는 최대 반복 횟수와 중단 조건(예: 같은 테스트 3회 연속 실패)을 적는다. 루프 중 사람이 코드를 직접 수정할 수 있으나(가재 모자), 수정 이유와 내용을 `INTERVENTIONS.md`에 기록한다. 16:45에 코드를 동결한다.

## 제출물

필수 제출물은 `AGENTS.md`, Loop 규칙 파일(`LOOP.md`), `DoD.md`다. 권장 제출물은 `npm install && npm run dev`로 실행되는 앱과 `README.md`, 실행 로그(`loop/logs/`, `PROGRESS.md`, `INTERVENTIONS.md`), 결과 보고서 1쪽(규칙 설계 의도, 규칙이 AI의 작업을 실제로 통제했는지, 한계)이다.


## 시작하기

준비물은 Node.js 22 이상, git, Claude Code(Claude Max 계정으로 로그인)다.

```bash
claude auth status        # loggedIn: true 인지 확인
npm install
npm run dev               # http://localhost:5173 에서 "서버 연결됨"이 보이면 준비 끝
```

`npm test`(Vitest)와 `npm run build`도 바로 돌아간다. 테스트 파일은 들어 있지 않다. 테스트는 각자의 DoD에 맞춰 루프가 만든다.
